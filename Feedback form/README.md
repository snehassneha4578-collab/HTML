# Feedback Form

This HTML page demonstrates a simple **Feedback Form** using basic HTML form elements.

## Form Elements Used

- Text Input (`<input type="text">`)
- Email Input (`<input type="email">`)
- Dropdown List (`<select>`)
- Text Area (`<textarea>`)
- Submit Button (`<input type="submit">`)
