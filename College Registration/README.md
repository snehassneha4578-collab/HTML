# College Registration Form

This HTML page demonstrates a simple **College Registration Form** using basic HTML form elements.

## Form Elements Used

- Text Input (`<input type="text">`)
- Dropdown List (`<select>`)
- Multiple Selection List (`<select multiple>`)
- Text Area (`<textarea>`)
- Submit Button (`<input type="submit">`)
- Reset Button (`<input type="reset">`)
